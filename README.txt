# Sorry — Really Really Sorry

A white + soft-pink, page-by-page apology experience made for a special friend.

## Included
- `index.html` — complete website structure
- `style.css` — white/pink responsive design, glass cards, animations
- `script.js` — page navigation, memory rendering, video playback, animated cursor/trail
- `content.json` — content payload
- `server.py` — optional Python local server
- `message.cpp` — optional C++ companion containing the core apology text
- `assets/` — the images and videos supplied with the project

## Run
### Easiest
Double-click `index.html`.

### Recommended (Python)
Open a terminal inside this folder and run:
`python server.py`

Then open:
`http://127.0.0.1:8000/index.html`

## Media note
The first click starts the experience and gives the browser a user interaction before media pages attempt autoplay. Modern browsers can still restrict autoplay with sound depending on their settings; every video has controls so playback can be started manually if needed.

## Pages
1. Main apology with a sad/emotional image
2. Heartfelt apology letter + supplied letter image
3. Vertical memories with a different deep sorry for every photo
4. Person's supplied video with its original audio
5. Supplied song/video
6. Second supplied song/video
7. Large special emojis: 🫣🥳😎

All supplied media filenames are kept exactly as provided.
